Orders → Google Sheet

Jo bhi order website par aaye ga woh khud Google Sheet mein ek nayi row ban kar aa jaye ga (WhatsApp wala order pehle ki tarah chalta rahe ga). Setup sirf ek dafa karna hai:

  1. sheets.google.com par nayi khali Google Sheet banayein (naam: Bin Imran Orders).
  2. Menu mein Extensions → Apps Script kholein, wahan ka purana code delete karke neeche wala code paste karein, phir Save (💾) dabayein.
  3. Deploy → New deployment → type Web app. Execute as: Me, Who has access: Anyone → Deploy. Google permission mange to Allow karein.
  4. Jo Web app URL mile (https://script.google.com/macros/s/.../exec) woh neeche pehle box mein paste karein.
  5. Apni Google Sheet ka normal link (browser ka address) neeche doosre box mein paste karein, phir Save.
  6. "Send test order" dabayein, Sheet mein "Orders" tab mein ek test row aani chahiye.
